markworkd: design

Status: v1 implemented in markworkd/ (Go, standard library only, no third-party modules). Section 16 lists where the implementation differs from or settles this draft.

markworkd is a small supervisor daemon, one per machine (the desktop and any VPS). It owns the agent processes that Markwork orchestrates.

Ask about this document…
1Dua ikon "≡"Ikon sidebar (format-justify-left) terlihat sama dengan ikon menu di kanan. Pengguna tidak tahu mana menu utamanya.
2Tiga tombol file berderetOpen File, Open Folder, dan New adalah tiga ikon dokumen/folder yang mirip, padahal ketiganya jarang dipakai dan sudah ada shortcut-nya.
3Save memakan tempatAutosave sudah ada, tapi tombol Save tetap tampil permanen tanpa memberi tahu apakah ada perubahan yang belum disimpan.
4Menempel ke tombol jendela"Text ▾" berada persis di sebelah minimize/close, jadi mudah salah klik dan grupnya tidak terbaca.
1Ikon sidebar yang jelasGanti ke sidebar-show-symbolic (persegi dengan panel kiri), sehingga hanya ada satu ikon "≡" di aplikasi.
2Satu tombol "+ New ▾"Klik untuk dokumen baru, caret untuk Open File, Open Folder, Board baru, dan Recent. Tiga tombol jadi satu split button.
3Judul sebagai status & switcherTitik biru berarti ada perubahan yang belum disimpan, dan "· Saved" muncul saat bersih. Klik judul untuk membuka Recent, Go to file, Rename, dan Save As. Tombol Save bisa dihapus (Ctrl+S tetap ada).
4Pemisah sebelum tombol jendelaGaris vertikal plus jarak memisahkan kontrol aplikasi dari minimize/maximize/close.
5Kontrol tampilan dikelompokkan"Text ▾" (sekarang memuat Source, Focus, dan Typewriter) diletakkan bersebelahan dengan toggle Assistant. Ikon Assistant diganti gelembung chat, bukan ikon orang. Di jendela sempit, label teks disembunyikan.
6Menu utama yang lebih pendekMenu dari 30+ item dipadatkan: baris aksi cepat (Commands, Find, Export) di atas, lalu Insert/Table dijadikan submenu, dan mode tampilan pindah ke "Text ▾".
