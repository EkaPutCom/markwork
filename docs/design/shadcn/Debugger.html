markwork editor

One command per thing the inspector shows. Output is JSON on stdout (--pretty for people); a failed check exits with 1, so an agent or CI can branch on it. Offsets are UTF-16, the same as CodeMirror's.

snapshot [--at cursor|POS]Text, selection, hidden ranges, prefixes, widgets and the parse tree around a place. The same as the top half of board 1.
press KEY… / type TEXTSends real keys to the view. --explain adds the transaction, which handler took it, and the checks after it.
select FROM [TO]Puts the cursor or a selection at offsets, or --visible "Jumat" by the text the eye sees.
log [--since N] [--flagged]The transactions tab: userEvent, changes, effects, selection before and after.
decorations [--line N]The decorations tab, with the builder that made each.
check [NAME…]Runs the checks on the current state. Names: round-trip, prefix-guard, backspace-visible, hidden-on-syntax, marks-closed, undo, tables, draw-time.
load / replay FILEA .mwrepro.json: the start, the steps, what was expected. Replay reruns the steps and the checks.
fuzzRandom keys on fixture texts, with every check after each step; a failure is saved as a repro, already shrunk to the fewest steps.
test-from FILEWrites a repro as a step for tests/electron/editor.mjs.
screenshot [--overlay]A PNG of the view, with the board 1 overlay if asked (for the screenshot AGENT.md asks for).
Only on when the window was started with --inspect-editor or MARKWORK_DEV=1, and only from this computer (the socket is in the user's runtime folder). A normal build has no inspector and no socket.
