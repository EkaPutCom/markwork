    Several ways in, like VS CodeThe split button in the header or a pane's ⋯ menu (Ctrl+Alt+\; Ctrl+\ stays the sidebar), dragging a tab or a file to the edge of a pane, or the tab's right-click menu. A drag shows where the tab will land before you let go.
    Every pane has its own tabs, view, and toolbarThe header's Visual / Markdown switch moves into each pane's bar once there is more than one, so the same file can be Visual on the left and Markdown on the right. The formatting toolbar belongs to a Visual text pane (it wraps in a narrow one); a Markdown pane is plain text and a board, list, or table has its own page, so neither has it. Point at a block in a Visual pane for its + (the / menu) and its grip.
    One file in two panes is still one documentBoth panes show the same text, so a change in one is in the other at once, and there is one Saved / Unsaved state and one undo history. Closing the last tab of a pane closes the pane. The sizes and which panes were open would be remembered per folder, like the tabs are.
