  • What is needed follows Preferences → Agents (harness-machine). In this window (the default): pi and git on this computer, markworkd optional (boards 1 and 2). This computer (markworkd): markworkd becomes needed too (board 4). An SSH machine: markworkd, pi and git are checked on that machine; this computer keeps only git, for History (board 3).
  • Where it is found: on this computer, the same lookup the app already uses to start the program (PATH, then ~/.local/bin and the other user folders), so "Installed" here means the card menu will find it too. Versions come from git --version, pi --version, markworkd version.
  • On a markworkd machine the check is a short run through the daemon, as daemonGit() already does, so it sees the same PATH and the same programs list the agent will. "Not allowed by markworkd" is a program the daemon refuses although it exists. While markworkd cannot be reached, pi and git there show as Unknown, not as missing.
  • Home shows only what is missing and needed; an optional program is never a warning. Hide keeps the section away until something changes. With everything in place the section is not there. Board 4 offers Run in this window instead, which sets Agents back to the default.
  • The dot on Programs in the sidebar shows while a needed program is missing.
  • The install command is per system (the tabs open on this one). Its text is still to be filled in from pi.dev and the git download page.
