Reference

Agent tool list

All the tools that the Markwork agent can call. Read tools run right away; proposal tools always wait for your approval in the review window.

Read tools

ToolFunctionApproval
list_filesThe list of Markdown files with word counts and headingsNo
search_documentsSearch sections of files by topic (BM25)No
search_textSearch for exact textNo
read_fileRead the contents of a file by line rangeNo
describe_schemaThe layout, options, fields (type, select options, default), and groups of a document that has layout: in its frontmatter; without a name, every such fileNo
query_notesFilter, sort, or count the notes of those documents by their fields (eq, lt, contains, empty, …; today for dates; count_by a field)No

list_files also shows the layout of a structured document, so the agent knows which files are boards, tables, calendars, and so on.

Git tools

Only available when the work folder is a Git repository.

ToolFunctionApproval
git_logThe latest commits of the folder or one fileNo
show_commitThe diff of one commitNo
file_at_commitThe contents of a file at an old commitNo

Proposal tools

ToolFunctionApproval
create_fileA new Markdown fileYes
edit_fileReplace exact text (once or every occurrence)Yes
insert_textInsert text at the start, at the end, or after a given lineYes
delete_fileMove a file to the TrashYes
move_fileRename or move to another folderYes
edit_noteOne note of any structured document: add, update (title, tags, fields), move, mark, delete, and groups; field values are checked against the declared fieldsYes
edit_schemaThe setup of a structured document: add or remove a field or a select option, reorder fields, switch the layout, set a layout optionYes
propose_batch1–20 of the actions above in one review, which may be applied partiallyYes

Work control tools

ToolFunctionApproval
set_workRecord the goal and up to 20 steps with their statusNo
verify_workCheck the actual result: text present/absent, a note in a group and its done status, the value of a note's field, Markdown structure and the fields of structured documentsNo

External harness

HarnessTriggered fromWorks in
piA kanban card marked @piThe project folder you choose, not the Markwork work folder

Availability requirements

  • The read and proposal tools are only offered when the Other files in the folder switch is on and a work folder is open.
  • One question runs at most 10 model rounds; the last round has no tools.
