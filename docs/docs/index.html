Getting started

Quick start

Markwork is a Markdown workspace for humans and AI agents on the Linux desktop. You and the agent work in the same folder: the agent browses your notes, plans, and task boards, then proposes changes that are only written after you approve the diff.

Install

The installers are attached to each release: an AppImage and a deb for Linux, a dmg for macOS, and an exe installer for Windows. The AppImage, the dmg, and the Windows installer update themselves from the releases; the deb is updated by installing the next one.

Diagrams (Mermaid and DBML) and HTML pages need nothing extra: they are drawn by the window itself.

Get the code and run it

Node.js 20.19+ or 22.12+ is needed.

git clone https://github.com/EkaPutCom/markwork.git
cd markwork
npm install
npm start

A file or a folder can be given after --:

npm start -- ~/notes            # open a work folder
npm start -- plan.md            # open one file

npm run electron:dist builds the installers of the current system into release/.

Connect the agent

  1. Open the Assistant panel with Ctrl+Shift+A or the bubble button in the header bar.
  2. Click the gear icon, then enter your DeepSeek API key. The key is stored in the system keyring, not in the app settings. The DEEPSEEK_API_KEY environment variable is also recognized.
  3. Open a work folder (Ctrl+Shift+O) so the agent can browse other files and propose changes.

Try a first flow

Markwork follows one flow through the day, all in plain Markdown files in your work folder:

  1. Home. Start on Home: what to continue, today's journal, running agents, due dates, and the unprocessed inbox.
  2. Inbox. Capture ideas and quick notes in the inbox, then turn the worthwhile ones into cards.
  3. Journal. Write short notes in the journal; Markwork adds the day's activity for you.
  4. Kanban. Plan the work on a board. Due dates show up on Home.
  5. Agent. Ask in the Assistant panel, for example “Update the release date and move the release material card to In Progress.” The agent proposes the changes, the review window shows the diff, and you press Apply or Reject.
